# 연료전지 손익분기 — 소매요금 기준 지역별

## 요약

- **질문**: 기존 차익 분석은 **도매**요금으로 손익분기를 냈다. 실제 구매는 소매인데, 지역별로 결론이 달라지는가
- **결론**: 달라진다. **권장 기준값 18원/MJ(도매)를 소매로 환산하면 32개 지역 전부가 일반용(을) 손익분기를 넘는다.** 육지는 1.2~7.6원/kWh 부족, 제주는 52.5원/kWh 부족
  - 기존 문서의 "소매 기준이면 손익분기가 그만큼 빡빡해짐"은 **과소 표현**이다. 빡빡해지는 게 아니라 **전 지역에서 마이너스로 돌아선다**
  - 산업용(을)은 육지 15.6~22.1원/kWh 여유로 유지된다. **요금 종별이 사업 성립 여부를 가른다**
  - **제주는 산업용(을)로도 29.2원/kWh 부족**하다. 제주 연료전지는 전기요금 차익으로 설명할 수 없다
- **원인**: 도매요금은 전국 단일이지만 도시가스사 공급비용이 지역마다 0.37~1.14원/MJ(제주 6.50) 붙는다

## 1. 계산 방법

기존 차익 문서([[2026.11.04_연료전지 전기요금·가스요금 차익 추세]])의 가정을 그대로 쓴다.

| 항목 | 값 |
|---|---|
| 연료전지 발전효율 | 43% → 1kWh 당 가스 3.6 / 0.43 = **8.3721 MJ** |
| 손익분기 지불단가 (기본요금 절감 포함) | 일반용(을) 고압A 선택Ⅱ **18.2279원/MJ**<br>산업용(을) 고압A 선택Ⅲ **21.0102원/MJ** |
| 가스 기준값 | **18원/MJ (도매)** — [[2026.11.04_연료전지 가스요금 기준값 검토(과거추세·용도비교)]] 권장값 |
| 지역 공급비용 | 2026-11-01 연료전지용 소매 − 도매 (DB 실측) |

손익분기 단가는 "지불하는 가스 단가"이므로 도매·소매 구분 없이 그대로 쓴다.
비교 대상만 바뀐다 — 도매 18 대신 **소매 환산 = 18 + 지역 공급비용**.

```
여유(원/kWh) = (손익분기 − 소매환산) × 8.3721
```

## 3. 읽히는 점

1. **일반용(을)은 전 지역에서 성립하지 않는다.** 도매 기준으로는 18 vs 18.2로 "거의 비긴다"였지만, 소매로 보면 가장 유리한 광주시조차 1.2원/kWh 부족하다. 기존 문서의 결론("연료비와 전기요금이 비기는 수준")은 도매 기준에서만 맞다
2. **종별 차이가 지역 차이보다 크다.** 육지 지역 간 차이는 최대 6.4원/kWh(광주 −1.2 vs 서울 −7.6)인데, 일반용(을)→산업용(을) 전환 효과는 약 23원/kWh다. **사업 성립의 관건은 입지가 아니라 요금 종별**이다
3. **제주는 다른 사업이다.** 공급비용 6.4953원/MJ은 육지에서 가장 높은 서울(1.1413)의 5.7배, 가장 낮은 광주(0.3709)의 17.5배다. 산업용(을)로도 29.2원/kWh 부족하므로, 제주 연료전지는 전기요금 대체 논리가 아니라 다른 근거(계통 제약, 재생에너지 출력제한 대응 등)가 필요하다
4. **수도권이 불리하다.** 서울 1.1413, 경기 1.0689로 공급비용 상위권이다. 데이터센터 입지가 수도권에 몰리는데, 가스 공급비용 측면에서는 가장 불리한 축이다
5. **공급비용은 느리게 오른다.** 서울 연료전지용 공급비용은 신설기 0.6859 → 현재 1.1413으로 7년간 +66% 올랐다. 도매요금처럼 매달 흔들리지 않지만 추세적으로 상승한다 — 장기 현금흐름에서 고정값으로 두면 낙관 편향이 생긴다

## 4. 기존 문서에 주는 수정 사항

[[2026.11.04_연료전지 전기요금·가스요금 차익 추세]] 4장의 손익분기 표는 도매 기준이다. 소매 기준으로는 다음과 같이 읽어야 한다.

| 전기요금 | 도매 기준 손익분기 | 소매 기준으로 필요한 도매요금 (서울) |
|---|---:|---:|
| 일반용(을) 고압A 선택Ⅱ | 18.2원/MJ | **17.1원/MJ** |
| 산업용(을) 고압A 선택Ⅲ | 21.0원/MJ | **19.9원/MJ** |

서울에서 일반용(을) 기준으로 비기려면 도매요금이 **17.1원/MJ 이하**여야 한다.
권장 기준값 18원/MJ도, 정상기 평균(2023.4.~2025.12.) 17.5원/MJ도 이 선을 넘는다.
이 선을 만족하는 과거 구간은 **2025년 평균(16.0원/MJ)** 수준이다.

## 5. 한계

- 공급비용을 2026-11-01 한 시점으로 고정했다. 지역별 공급비용은 시·도지사 승인 사항이라 개정 시점이 지역마다 다르다
- 2026-11-01 소매요금은 원본 엑셀의 도매란이 10월 값이어서 **11월 도매 인상이 반영되지 않은 값**이다 (`docs/HOW-TO-QUERY.md` §10). 다만 이 분석은 소매−도매 **차액**만 쓰므로 영향이 상쇄된다
- 손익분기 전기요금(139.9 / 161.0원/kWh)과 기본요금 절감(12.7 / 14.9원/kWh)은 기존 문서 값을 그대로 썼다. 전기요금 전망 시나리오별 변동은 [[2026.11.04_전기요금 전망(2027~2030)]] 참조
- 부가세 10%와 열회수분 공제는 미반영 (양쪽 모두 부가세 별도이므로 비교에는 영향 없음)

## 재현 쿼리

```sql
-- 발전효율 43% → 1kWh = 3.6/0.43 = 8.3721 MJ
with k as (select 3.6/0.43::numeric as mj_per_kwh),
m as (
  select r.region, (r.won_per_mj - w.won_per_mj) as margin
  from citygas_retail_monthly r
  join citygas_wholesale_monthly w
    on w.effective_from = r.effective_from
   and w.use_category = r.use_category and w.use_detail = r.use_detail
  where r.use_category = '연료전지용' and r.effective_from = '2026-11-01')
select m.region,
       round(m.margin, 4)                                        as 공급비용,
       round(18 + m.margin, 2)                                   as 소매환산,
       round((18.2279 - (18 + m.margin)) * k.mj_per_kwh, 1)      as 일반용을,
       round((21.0102 - (18 + m.margin)) * k.mj_per_kwh, 1)      as 산업용을
from m cross join k order by m.margin;
```
