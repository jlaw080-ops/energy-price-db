# 연료전지 가스요금 기준값 검토 — 과거 추세와 용도별 비교

## 요약
- **질문**: 연료전지 경제성 평가의 가스요금 기준을 "과거 평균"과 "미래 예측" 중 무엇으로 잡을 것인가
- **결론**: 단순 과거 평균(16.8원/MJ)은 쓰지 않는다. **정상기 평균(2023. 4.~2025. 12., 17.5원/MJ)과 유가연동 예측(2028~2030년 18.2~18.9원/MJ)이 같은 값으로 모이므로 기준값은 18원/MJ(도매, 부가세 별도)를 권장**한다
  - 단, 2027년은 국제 고유가가 늦게 반영돼 약 24원/MJ 수준. 연차별 계산에서는 2027년을 따로 둔다
  - 민감도: 낮음 15.9 / 기준 18 / 높음 21.6 / 현재 25.1원/MJ
- **용도 비교**: 연료전지용은 열병합·산업용과 같은 원료비를 쓰고 공급비만 낮다. 그래서 늘 이들의 92~96% 수준으로 움직이고, 국제가 변동을 **매달 그대로** 받는다. 정부가 인상을 억제하는 민수용(주택·일반)과는 다르게 움직임

## 3. 읽히는 점

1. **연료전지용 = 열병합 원료비 + 낮은 공급비.** 원료비는 열병합용과 같은 도시가스발전용 원료비. 공급비 0.6804원/MJ는 신설 이후 7년간 변동 없음. 요금 변동의 거의 전부가 원료비(유가·환율·현물 LNG)에서 나온다
2. **국제가를 매달, 약 5~7개월 늦게 그대로 반영.** 유가 바닥(2020. 4.) → 국내 최저(2020. 11.), 유가 정점(2022. 6.) → 국내 최고(2022. 12.)
3. **민수용과는 움직이는 방식이 다르다.** 주택·일반용은 정부가 인상을 억제·분산해 2016~2026년 12~21원/MJ에서 완만히 올랐다. 연료전지는 같은 기간 7.9~31.0원/MJ로 크게 오르내렸다. 위기 때(2022년)는 민수용보다 훨씬 비싸고, 안정기에는 더 싸다
4. **바닥 수준이 올라갔다.** 2019~2021년 평균 11.3원/MJ는 브렌트 60달러대, 환율 1,150원대 시절 값. 지금 환율은 1,400원대로 25% 높아, 같은 유가라도 원화 원료비가 25% 높다. 2020년 같은 7~10원/MJ가 다시 나오려면 유가 40달러대가 필요하다

## 4. 기준값 판단 — 과거 평균 vs 미래 예측

### 후보 값 (연료전지용 도매, 원/MJ)

| 후보 | 값 | 평가 |
|---|---:|---|
| 신설 후 전체 평균 (2019. 5.~2026. 11.) | 16.8 | 코로나 저점과 2022년 급등이 섞임. 환율 1,150원 시절 값이 포함돼 **낮게 나옴** |
| 신설 후 중앙값 | 17.1 | 극단값 영향은 적지만 같은 환율 문제 |
| 저가기 평균 (2019. 5.~2021. 10.) | 11.3 | 현재 환율로는 재현 어려움. **사용 부적합** |
| 위기기 평균 (2021. 11.~2023. 3.) | 23.9 | 위기 시 민감도 상한으로만 사용 |
| **정상기 평균 (2023. 4.~2025. 12.)** | **17.5** | 브렌트 70~80달러, 환율 1,300~1,420원. 현재 환경과 가장 비슷 |
| 최근 5년 평균 (2021. 11.~2026. 11.) | 19.6 | 위기기 포함으로 다소 높음 |
| 유가연동 예측 2028~2030년 (기준) | 18.2~18.9 | EIA·골드만 유가 전망 + 환율 1,400원. 계수 정상화 시 16~17 |
| 낙관 시나리오 A 2030년 | 17.6 | TTF 하락분 50% 반영 |
| 현재 (2026. 11.) | 25.1 | 위기 프리미엄 포함. 2027년 상반기까지 유지 전망 |

### 권장

- **기준값 18원/MJ.** 정상기 평균(17.5)과 미래 예측(18.2~18.9)이 같은 범위로 모인다. "과거 근거"와 "미래 근거"를 모두 댈 수 있는 값이라 보고서 설명력이 높다
- **2027년은 따로 둔다.** 국내 요금이 국제가를 늦게 따라가 2027년 평균은 약 24원/MJ. 연차별 현금흐름 계산이면 2027년 24, 2028년 이후 18을 쓴다. 단일값 계산이면 18을 쓰되 "2027년 단기 고가 구간 존재"를 주석으로 단다
- **민감도 범위**: 15.9 (공급과잉·저유가) / 18 (기준) / 21.6 (고유가 지속, 보고서 기존 연 -3.4%와 같은 수준) / 25.1 (현재 유지)
- **"과거 평균"을 쓴다면 반드시 기간을 밝힌다.** 신설 후 전체 평균(16.8)은 환율이 낮던 시기를 포함해 경제성을 실제보다 좋게 보이게 한다

## 5. 남은 과제

- **전기요금(수익 측)과 같이 봐야 한다.** 연료전지 경제성은 가스요금 단독이 아니라 "전기요금 + REC·임대료 − 가스요금"의 차이로 결정된다. 2022~2024년 한전 요금 인상으로 수익 측도 올랐으므로, 같은 기간의 전기요금 추세를 붙이면 "가스가 비쌌던 2022년에도 차익이 났는가"를 확인할 수 있다 (레포에 한전 요금표 2021~2026 보유)
- 2019. 5. 이전 연료전지 적용 요금(열병합용 여부) 확인
- 2026. 11. 타 용도 도매요금(가스공사 공시) 반영
