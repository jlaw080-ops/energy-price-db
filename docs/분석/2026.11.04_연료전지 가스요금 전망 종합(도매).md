# 연료전지 가스요금 전망 종합 (도매요금 기준)

## 요약
- **범위**: 한국가스공사 **연료전지용 도매요금**만 다룸 (소매요금·지역별 도시가스사 마진 제외, 부가세 별도)
- **과거**: 2019. 5. 신설 이후 7.93 ~ 30.99원/MJ 범위에서 변동. 변동은 전부 원료비에서 발생 (공급비 0.6804원/MJ 고정)
- **현재**: **25.0573원/MJ** (2026. 11. 1.) — 2026. 4. 대비 +70%, 상승 진행 중
- **전망 (2030년)**: 기준 21.8 / 낙관 A 17.6 / 낙관 B 10.2원/MJ → 월 차이 +13.5 / +15.8 / +19.9만 원/kW
- **판단**: 보고서에는 낙관 A 사용. 단, 2027년 상반기까지는 하락보다 추가 인상 위험이 큼

### 이력에서 읽히는 점
- **공급비는 2019년 이후 0.6804원/MJ로 고정.** 요금 변동은 전부 원료비(장기계약 LNG, 유가 연동) 변동임
- **국제 가격보다 몇 달 늦게 따라감.** 2022년 국제 가스가격 정점(8월) → 국내 연료전지용 요금 정점(12월)
- 매월 원료비 연동으로 바뀌므로 한 해 안에서도 변동 폭이 큼 (2022년 17.5 ~ 31.0)

## 4. 해석과 주의점

- **낙관 A (2030년 17.6원/MJ)**: 2023~2025년 연평균(16.0~20.3) 범위 안. 최근 실적으로 뒷받침되는 값이라 보고서용으로 적절
- **낙관 B (2030년 10.2원/MJ)**: 이보다 낮았던 때는 2020~2021년 코로나 시기뿐. 다만 2022. 12.→2025. 11.에 실제로 -56% 하락한 적이 있으므로 "불가능"이 아니라 "드문 극단값"으로 표기
- **단기 리스크 — 2027년 상반기 추가 인상 가능성**: 국내 요금은 국제가를 몇 달 늦게 따라가고, 2026. 4. 이후 상승이 아직 멈추지 않음. "2027년부터 하락 반영"은 낙관적인 시점 가정
- **근거 지표 보완 필요**: 국내 원료비는 유가 연동 장기계약 중심이라 유럽 TTF와의 연결이 약함. 유가(브렌트·JCC) 전망을 함께 근거로 제시하면 더 단단함
- **비관 시나리오 미작성**: Société Générale 전망(공급 과잉 2028년 말로 지연)이나 2022년형 급등을 반영한 비관 케이스는 아직 없음
